메일크래프트

보내기 전에 나랑 한 번 더 확인해요! ✉️

신입 회계사를 위한 메일 친구. 상황·대상·톤을 고르면 삼일 포맷 초안을 만들고, 참조 누락까지 짚어드려요.

디자인을 귀엽게 바꾸고 마스코트 '메일이'를 넣었어요. 신입이 부담 없이 여는 도구가 되도록.

모범 메일 8선

하이라이트 = 받는 사람이 꼭 봐야 할 곳
3개 → 8개(업무 흐름 순). 카드마다 제목·받는 사람·참조(직급순)를 보여 주고, '왜 모범인가'를 육하원칙 + 가독성 포인트로 자세히 풀었어요.

메일 작성

123
① 메일 상황 누구에게, 왜 보내는지 한 번에 골라요
사유 선택이 새로 생겼어요(8종). 사유마다 '다름 아니라~' 문장과 제목이 자동으로 바뀌어요.
✏️ 상황별 입력 고른 상황에 꼭 필요한 칸만 보여요. 입력한 값으로만 메일을 써요 (없는 내용은 지어내지 않아요).
원본은 대상·기한·형식 칸을 채우는 방식이었는데, 내 말 메모를 받는 방식으로 바꿨어요.
메모 대신 사유별 입력 칸으로 바꿨어요. 상황마다 필수 칸(✅/○)이 다르고, 필수 칸이 비면 초안을 만들기 전에 빨간색으로 짚어 줘요. 칸에 안 맞는 내용은 '추가로 전할 말'에 적어요. '메일 보내는 사유'와 '받는 대상'을 합쳐 '메일 상황' 하나로 고르게 바꿨어요(예: 고객사에게 자료 요청). 지금은 5개 상황만 켜 두었고, 나머지는 완성 후 추가할 예정이에요.
② 받는 대상
4종(임원/고객사/협력사/사내) → 5종. 사내는 삼일 호칭대로 '선생님'으로 불러요.
② 원하는 톤
격식·친근 2개 → 5개(간곡·긴급·감사 추가).
톤은 격식·간곡 두 가지만 남겼어요. 긴급(고객사에 부담)과 감사(인사 한 줄이면 충분)는 뺐어요. 받는 대상의 사수·동료 선생님은 '법인 내 선생님'으로 합쳤어요.
'친근' 톤을 뺐어요. 이메일은 모두 정중한 격식체로 쓰고, 가벼운 연락은 팀즈로! 남은 톤은 모두 존댓말이고 상황별 강조만 달라요.
③ 기본 정보 비워 두면 ○○ 자리표시로 남아요
④ 추가 문구 (선택) 카테고리마다 하나씩 골라요
명절 인사 하나 → 설·추석·새해·크리스마스·안부·결산 시즌 등 카테고리별 추천 문구. '첫머리/끝인사' 위치도 표시돼요.

초안 고르기

123
모든 초안이 삼일 기본 포맷(안녕하십니까 → 소속·이름 → 첫 인사 → 다름 아니라 → 본론 → 안부 → 드림)과 제목 머리말 규칙([삼일회계법인] / [회사명])을 따라요.
입력 칸의 값을 사유별 메일 양식 틀에 넣어 써요. 같은 값을 넣으면 항상 같은 메일이 나와요.

보내기 전 확인

123
체크박스 4개 → 자동 점검 팝업. 참조 누락, 프로젝트 인원 누락, 직급 순서, 외부 주소 섞임, 첨부·기한·○○ 남음에 더해 첨부 보안(암호·비밀번호 별도 발송), 파일 이름 규칙, 답장 시 원래 참조 유지까지 확인하고, 리마인드 메일로 바로 이어 쓸 수 있어요.
최종 메일
오른쪽 프로젝트 인원에서 원래 메일의 참조 인원에 '원래 참조'를 눌러 표시해 주세요. 답장할 때 빠지지 않았는지 확인해 드려요.
